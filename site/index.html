Свой VPN целиком.

Протокол, ноды, панель и приложения для Android и Windows — одним комплектом. Тот, кто раздаёт доступ, ставит панель одним скриптом. Тот, кто подключается, получает одну ссылку, а приложение само выбирает ноду и уходит с замолчавшей на живую.

Как устроено

Панель управляет доступом, пакеты идут через ноду мимо панели. Код открыт целиком, сборки собираются на GitHub из тега и подписаны.

Протокол VP1

Отдельная Noise-сессия внутри TLS, REALITY, WebSocket или QUIC. Криптография — готовые примитивы, своих нет. Рядом VLESS и Trojan — путь переезда с чужих панелей.

Приложения

Android и Windows: сами выбирают ноду, российские сайты можно пустить напрямую, диагностика по шагам, напоминание продлить. Android принимает и чужие ключи: VLESS, Trojan, WireGuard и другие.

Панель продавца

Клиенты, тарифы, сроки и трафик, QR и текст для Telegram, API для бота, копии базы, страница статуса нод для канала. Переезд с Marzban и 3x-ui с прежними ссылками.

Своя панель за десять минут

Нужны Linux-сервер с systemd и домен. Компилятор не нужен: скрипт сам скачивает сборку, сверяет сумму и получает сертификат Let’s Encrypt.

  1. Домен на сервер

    У регистратора домена заведите запись A на адрес сервера, например panel.example.com.

  2. Панель одной командой

    На сервере под root. В конце скрипт один раз покажет админский токен — сохраните его.

    curl -fsSL https://github.com/jytt8u/marvia/releases/latest/download/install-panel.sh -o install-panel.sh
sudo sh install-panel.sh --domain panel.example.com --email you@example.com

  3. Нода — строкой из панели

    В панели «Ноды» → «+ Нода»: панель выдаёт готовую команду для второго сервера. Если нода стоит на том же сервере, что и панель, панели нужен другой порт: --port 8443.

  4. Ключ покупателю

    «Клиенты» → «+ Клиент»: ссылка marvia://, QR-код и готовый текст для Telegram.

Подробно, с проверкой сумм и разбором ошибок, — «Свой VPN с нуля».

Скачать

Все файлы лежат в выпусках на GitHub. Свежая тестовая сборка — вверху списка. Суммы файлов подписаны через Sigstore, APK — одним ключом с первого выпуска.

Выпуски: Android APK и Windows Как проверить файл Не подключается

Для Android: marvia-android.apk; обновлять удобно через Obtainium. Для Windows: marvia-windows-setup.exe — в нём уже всё. SmartScreen встретит предупреждением, пока у файла нет платной подписи: «Подробнее» → «Выполнить в любом случае».

Чего проекта нет и не будет

  • Своего платёжного шлюза. «Продлить» ведёт к продавцу — на его страницу или в бота.
  • Хостинга нод за продавца. Сервер арендует сам продавец; проект не стоит между ним и покупателями.
  • Панели на телефоне. Панель — в браузере; на телефоне — приложение для подключения.
  • Обещания, что VPN защищает от всего. Что видит нода и чего не видит продавец — docs/privacy.md.
